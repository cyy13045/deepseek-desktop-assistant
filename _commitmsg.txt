多服务支持、语音暂停与设计音色、修复窗口不上屏、双语 README

聊天与语音都改成多服务结构，可随时切换：

- 抽出 providers 层：三套协议适配器（OpenAI 兼容 / Anthropic Messages / Google Gemini）
  + 15 个聊天预设 + 3 个语音预设；DeepSeek 专有逻辑并入 openai 适配器，删除 deepseek.js
- 自定义 API：Base URL / 认证方式（含 Azure 的 api-key 头）/ 自定义请求路径 /
  额外请求头 / 输出上限参数名，全部可在设置里改
- 能力位驱动界面：supportsVision 决定是否发送截图并给出降级提示，supportsVoiceDesign
  决定是否显示音色设计，thinkingParam 决定是否发送 thinking 参数
- store 改为 providers 结构，旧版顶层 deepseek/mimo 配置自动迁移并落盘升级，密钥仍是 DPAPI 密文
- 语音新增暂停 / 继续：暂停同时冻结播放与后台合成，避免暂停期间继续请求接口
- 设计音色：voicedesign 的结果固化为参考音频，之后由 voiceclone 复用，
  避免逐块调用导致的音色漂移
- 修复窗口内容不上屏：该机 Electron GPU 呈现失效（isVisible/isAlwaysOnTop/capturePage
  都正常，但屏幕上没有任何内容），改为默认关闭硬件加速；并定期 re-raise 置顶窗口
- 新增 --diag 渲染诊断模式
- README 改为中英双语；新增 electron-builder 构建配置与应用图标

验证：selftest 全通过；probe-providers 自定义 API 15/15；ui-check 渲染与 IPC 流程通过
